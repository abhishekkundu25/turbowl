# Security

## Supported versions

Only `main` is supported. There is no release with security fixes yet.

## Reporting a vulnerability

Report a vulnerability privately, through a GitHub security advisory:
<https://github.com/abhishekkundu25/turbowl/security/advisories/new>.
Do not open a public issue for it.

Include the input or code that shows the problem, the version or commit,
and what happens. A crash, a hang or unbounded memory on a small input is
worth reporting. The known resource limits are listed under "Known
limitations" in `README.md`.
