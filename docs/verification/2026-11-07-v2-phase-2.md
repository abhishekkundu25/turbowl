# Verification: version 2, phase 2 close-out (2026-11-07)

The state at the end of phase 2 (`docs/specs/v2-2-speed.md`): TurbOWL's own
parsers, parallel parsing and rounds, snapshots, and the improvement loop's
iterations 1 to 11 (`docs/specs/experiments.md`), at commit `1faa436` (the
code of `b654de6`; later commits are records; one race step ran at `d662fe0`,
a docs-only commit with the same code).

- **Correctness** ran in full: every suite, the slow tier and 100,000 chaos
  iterations of each kind. Each chaos iteration also compares one thread
  with all cores.
- **The race** is the short one the owner asked for: the editor-size
  scenarios only, against Nemo, Soufflé and VLog, in both configurations,
  with TurbOWL on one thread and on all cores. A competitor run that passed
  3 times TurbOWL's time could be stopped, by the owner's rule. The
  full-size race is ticket 27.
- **The machine was busy**, with a 1-minute load average of 3 to 5 during
  the race, not quiet. The gaps between engines are many times the spread.

Raw results are in [`data/2026-11-07-v2-phase-2/`](data/2026-11-07-v2-phase-2/):
the race's result files (`R-*`), `scoreboard.txt`, `snapshot.txt`,
`race.log` with each step's load average, `w3c.log`,
`chaos-100k-summary.txt` and `slow-tier.txt`.

## The race (editor-size scenarios)

Total time (load and reasoning), median, and peak memory: the largest run, in MiB as
the bench prints it (the budget's 517.3 MB is in millions of bytes). TurbOWL's
competitors run the same rules. Their times are their own reports, which for
VLog leave out the JVM's start.

## Data-size scenarios, TurbOWL alone

One run each, for the record (no competitor raced them in this phase; ticket
27). Total time on one thread and on all cores, with the all-cores peak:
claros-l 13.1 s and 5.6 s (5.7 GB); uobm-010-u 1.48 s and 0.71 s; owl2bench-rl-5
5.34 s and 3.27 s (3.3 GB); lubm-uba-100-l 8.76 s and 7.89 s. Nothing passed 6
GB. lubm-uba's load does not get faster on all cores: its data is RDF/XML,
which Oxigraph's parser reads on one thread.
