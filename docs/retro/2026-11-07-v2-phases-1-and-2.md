# Retrospective: version 2, phases 1 and 2 (2026-11-07)

Candidates for changing how this project works, drawn from the departures
logged in `docs/tickets/v2/README.md`, the slices sent back, and the checks
that failed. Most severe first. None is applied: each changes the repo's
environment or its tools, which is the maintainer's call.

1. **A slice's pytest tested the main checkout.** The `.venv` that
   the parallel worktrees' setup clones keeps console scripts pointing at the main
   checkout's environment, so `uv run pytest` in a worktree imported the main
   checkout's package. Ticket 19 found it; the merged-tree runs after each
   landing were valid. Fix: the setup of a parallel worktree runs
   `uv sync --reinstall` in `crates/python`, or does not clone `.venv`.
2. **Settle the defaults before a long benchmark.** Phase 1's race measured
   the old defaults while the switch measurement that changed them ran in the
   same session, so its default tables measured a configuration that no
   longer exists.
3. **Every result records its real thread mode.** After ticket 17 the bench
   ran TurbOWL on every core while its results said one thread, until
   `--threads` (`0531ead`). A check that the recorded mode is the mode run
   would have caught it.
4. **Judge a noisy peak by medians of alternating runs.** The bench's largest
   of three runs is noise on all cores; iterations 4 and 5 were misread until
   iteration 6's reviewer read the per-run peaks.
5. **Evaluate overlapping changes stacked, not alone.** Iteration 9 gave 45 MB
   on its own and 7.5 MB on top of iteration 8: both freed memory the
   parallel steps reuse.
6. **Ported code keeps its notice from the first commit.** Ticket 16's slice
   ported oxttl and oxiri without Oxigraph's MIT notice
   (`THIRD-PARTY-NOTICES.md` was added at review).
7. **Ask before a multi-hour run, and stop slow competitors early.** The
   phase 1 session ran 4 hours before the maintainer stopped it; the maintainer's
   3-times rule (ticket 27) bounds the next one.
8. **Shell scripts run under bash, with guarded arrays.** zsh does not split
   unquoted variables, and macOS's bash 3.2 fails on empty arrays under
   `set -u` (`${a[@]+"${a[@]}"}`).
9. **A ticket that touches the minimal inputs includes pytest**, and an oracle
   fault is checked against the W3C text before it is declared (phase 1,
   tickets 10 and 26).
